# Radio Wave — логотипы и адаптивный интерфейс

Изменения в этой версии:
- логотип станции из поля `favicon` каталога Radio Browser;
- если логотип не указан, используется favicon домена аудиопотока;
- если изображение недоступно, показывается значок радио;
- сохранение URL логотипа вместе с сохранёнными станциями Radio Browser;
- на широких экранах (от 720 dp) список станций и отдельная панель выбранной станции/плеера отображаются рядом;
- на телефонах и более узких экранах сохраняется компактный вертикальный список;
- логотипы отображаются как в списке, так и в панели выбранной станции.

## Сборка
Откройте папку проекта в Android Studio и выполните Sync Project with Gradle Files, затем Build > Make Project.
Для загрузки Coil и остальных зависимостей требуется интернет. Сборку в этой среде проверить не удалось, потому что Gradle не смог скачать дистрибутив из-за отсутствия сетевого доступа.
