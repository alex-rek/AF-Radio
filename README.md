# AF Radio

Android-приложение интернет-радио на Kotlin, Jetpack Compose и AndroidX Media3.

## Возможности

- Встроенные станции, свои станции по URL и каталог Radio Browser.
- Поиск и выпадающие фильтры страны, языка и жанра.
- Избранное с сохранением порядка после перетаскивания.
- Фоновое воспроизведение, системные медиакнопки и переключение избранного через Bluetooth.
- Настройка продолжения воспроизведения после отключения Bluetooth.
- Выбор раздела при запуске, цвета элементов и светлой, тёмной либо системной темы.
- Дневной и ночной фон, отдельные изображения для горизонтальной ориентации.
- Русский, украинский, английский, немецкий, испанский, португальский и упрощённый китайский интерфейс.
- Адаптивная разметка телефона и планшета, трёхполосный эквалайзер и настройка буфера.

## Сборка

1. Откройте корневую папку проекта в Android Studio.
2. Настройте Android SDK Platform 35 и дождитесь Gradle Sync.
3. Используйте JDK, соответствующий `gradle/gradle-daemon-jvm.properties` (сейчас JetBrains JDK 25). Целевой уровень Java приложения — 17.
4. Запустите приложение кнопкой Run или соберите debug APK:

```powershell
.\gradlew.bat :app:assembleDebug
```

APK находится в `app/build/outputs/apk/debug/`.

`local.properties` содержит локальный путь к Android SDK и не входит в Git. Android Studio создаёт этот файл на компьютере разработчика. Для первоначальной загрузки зависимостей требуется интернет.

## Подписанный release APK

Для установки релиза и последующих обновлений используйте постоянный ключ подписи. Скопируйте `keystore.properties.example` в `keystore.properties` и заполните путь, alias и пароли своего ключа. Реальный файл настроек и ключ подписи не публикуются в Git.

```powershell
.\gradlew.bat :app:assembleRelease
```

Подписанный APK создаётся в `app/build/outputs/apk/release/`. Без `keystore.properties` release-сборка остаётся неподписанной. Для каждого следующего релиза увеличивайте `versionCode` и обновляйте `versionName` в `app/build.gradle.kts`.

## Радиостанции

Для добавления своей станции нужен прямой HTTP/HTTPS URL аудиопотока. Адреса потоков и доступность станций могут меняться. Аудио загружается непосредственно у станции; приложение не проксирует потоки. Поиск в Radio Browser требует подключения к интернету.

## Локальные файлы

Кеши Gradle и Android Studio, результаты сборки, локальные пути, файлы окружения и ключи подписи исключены через `.gitignore`. Ключ подписи release-версии храните отдельно от репозитория.
