# Radio Wave — адаптация для планшетов

Основа: RadioWave_userproject_v3, включая Radio Browser.

## Изменения
- Добавлен адаптивный контейнер для основного списка.
- При ширине доступной области от 600 dp увеличиваются боковые отступы.
- При ширине от 840 dp применяется более широкое центрированное поле отступов.
- На узких экранах сохраняется компактная компоновка.
- Radio Browser, логотипы, избранное, Media3 и системные отступы оставлены из исходного проекта.

## Сборка
Откройте проект в Android Studio и выполните Build → Build APK(s).

Примечание: компиляция этого архива не проверена в текущей среде. После сборки проверьте портретную и альбомную ориентацию на устройстве.
