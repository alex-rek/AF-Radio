# AF Radio — изменения

- Название проекта и приложения: AF Radio (Arctic Fox).
- Добавлена иконка арктического лиса в заголовок и как launcher icon.
- Поле поиска убрано с главного экрана; поиск открывается кнопкой-лупой в заголовке.
- Кнопка-шестерёнка открывает настройки.
- В настройках доступны русский, украинский, английский, немецкий, испанский и португальский языки; тёмная/светлая тема; буфер предзагрузки 0–5 секунд; трёхполосный эквалайзер.
- Настройки сохраняются в SharedPreferences.
- Эквалайзер подключён к системному Android Equalizer, если он поддерживается устройством. На устройствах без эффекта системного эквалайзера приложение продолжит работать без него.
- Значение буфера читается службой воспроизведения при её запуске, поэтому после изменения буфера нужно остановить и заново запустить воспроизведение/службу.
- Сохранены Radio Browser, избранное, ручное добавление станций, логотипы и адаптивная раскладка планшета.

## Проверка
Сборка в этой среде не выполнена: Gradle Wrapper не смог загрузить дистрибутив Gradle из-за отсутствия DNS/сетевого доступа. Откройте проект в Android Studio и выполните Gradle Sync и Build.
